# Rooom

[![License: GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-blue.svg?style=flat-square)](LICENSE)

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

いま使っているコーディングエージェントのための小さなウィンドウ。アプリを切り替えずに、承認、回答、返信ができます。

## 状況

計画段階です。コードはまだなく、インストールできるものもありません。これまでの決定、提案中の設計、未決定の項目はすべて [PLAN.md](PLAN.md) にあります。

## できるようになること

- Claude デスクトップアプリ、Codex Desktop、Antigravity、DeepSeek Harness で実行中のセッションと、そのうちどれがあなたを待っているかを表示します。
- 1 本のタイムラインで、リクエストの承認、質問への回答、返信の送信ができます。各メッセージの状態（待機中、受信済み、開始済み）も表示します。
- エージェント同士が MCP でメッセージをやり取りでき、そのすべてがあなたに見えます。
- 邪魔になりません。ふだんは画面端の細い帯で、ポインターを近づけたときやエージェントがあなたを必要とするときにだけスライドして現れます。まず Windows に対応します。

## しないこと

- 会話の実行や所有。セッションはそれぞれのアプリに残ります。
- 他のアプリの設定の変更。Rooom は追加する内容を示すだけで、追加はあなたが行います。
- 会話のコピーの保存。
- クォータやトークン使用量の追跡。

## 予定している技術スタック

本体は Rust と Tauri 2、インターフェースは React 19、エージェント間メッセージは公式の Rust MCP SDK を使います。

## 参考
